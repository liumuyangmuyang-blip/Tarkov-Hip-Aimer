# 取消开镜修复验收记录

日期：2026-10-28。

## 完成的行为

- 点一下切换开镜时，默认 Tab、Esc 将工具记录清为未开镜；同一帧取消优先。
- 每个取消键分别记录按下事件，按住一个再按另一个也能取消。
- “按键 → 取消开镜 → 配置取消键”支持添加、移除、清空和恢复默认，支持 Tab、Esc、字母和鼠标键。
- 编辑放弃时不修改原配置，保存后进入既有设置发布和保存流程。
- 旧设置缺少新字段时使用 Tab、Esc；显式空列表表示禁用，不会自动补回默认键。
- 背包中右键后，通过配置的取消键退出即可重新对齐；不单独控制背包内显隐。

## 人工游戏验收步骤

1. 启动更新后的程序，确认工具“开镜方式”与游戏一致，选择“点一下切换”；取消开镜键保留 Tab、Esc。先确保游戏处于未开镜状态，再按一次取消键对齐。
2. 右键开镜，瞄准点应隐藏。Tab 打开背包，再 Tab 关闭；退出后瞄准点应显示。再次右键开镜应隐藏，再次关镜应显示。
3. 分别在背包中右键物品 0、1、2、3 次，最终用 Tab 退出；每次退出后均重复一次开镜、关镜检查。
4. 重复上一步，最终用 Esc 退出。若第一次 Esc 只关闭物品菜单，继续 Esc 直到实际退出背包，再检查开关镜。
5. 在工具中录入一个与游戏实际操作匹配的新取消键，保存并重启工具，确认绑定仍保留；按键已移除时不应再触发取消。
6. 连续按取消键不应把记录翻成开镜。换手和强化准星启用后，取消开镜不应将它们重置。
7. 如切回按住开镜方式，按住时隐藏、松开时显示的原有规则应保持不变。
