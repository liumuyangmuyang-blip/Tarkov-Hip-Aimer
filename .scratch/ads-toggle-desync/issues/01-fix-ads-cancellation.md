# 01：取消开镜后恢复正确的瞄准点显隐

Status: ready-for-agent
Resolution: completed

Blocked by: None

需求：[spec.md](../spec.md)。

## 要完成的行为

按需求说明修复点一下切换开镜的显隐反转。默认用 Tab、Esc 清掉工具记录的开镜状态，支持配置多个取消开镜键。
背包中右键任意次数后，经配置的取消键退出，未开镜时瞄准点显示，再开镜时隐藏。
不判断背包是否打开，不单独控制背包内显隐，按住开镜和其他状态保持原有行为。

## 验收条件

- [x] 开镜后 Tab 打开并关闭背包，退出后瞄准点显示，再次开镜隐藏，继续开关镜不反转。
- [x] 背包里分别右键 0、1、2、3 次，用 Tab 或 Esc 退出后均恢复正确显隐。
- [x] 默认 Tab、Esc 都能取消工具记录的开镜状态；重复取消始终保持未开镜。
- [x] 同一帧取消和开镜时取消优先，仍按住开镜键不会在下一帧产生额外开镜；松开再按恢复正常。
- [x] 设置中可以配置多个取消开镜键，修改后立即生效，保存重启后保留。
- [x] 旧配置缺少新设置时补齐默认取消键；删除或修改默认绑定后遵守新配置。
- [x] 按住开镜保持原有行为；取消操作不重置换手、强化准星及其他运动状态。

- [x] 说明文字明确取消键只是对齐工具记录，不会向游戏发送按键，也不代表能识别菜单状态。
