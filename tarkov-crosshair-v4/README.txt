Tarkov Hip Aimer（塔科夫腰射准星）— by Leo   v5.1

★ 必读 ★
1. 战术装置强烈推荐 WMX200，用它的红外（IR）模式；别的战术装置也一样，用红外模式。
2. 不要同时开准星和可见激光：两个点会混在一起，看不清。
3. 强化键 = 游戏里「切换战术装置模式」的键（默认 Ctrl+T）。按一下切到手电，强化准星就亮起来，近距离更好看清；再按一下切回红外，强化关闭。
   战术装置本身用 T 打开，一直开着就行；T 和强化没有关系。

第一次用，先做这 3 步：
1. 双击「准星 TarkovHipAimer.exe」，会先出现「首次设置向导」，一页一页照着游戏里的设置填就行（游戏分辨率、画面比例、FOV 等）。
2. 向导最后会问要不要看教程。教程可以跳过，以后随时再看。
3. 进游戏打几发。觉得哪个方向有偏差，再到对应的页面细调。

==================================================
【这是什么】
==================================================
塔科夫腰射用的屏幕准星。
屏幕上画一个准星，跟着你的走路、侧身、开枪、跳跃、换手一起移动，
告诉你不开镜时子弹大概落在哪里。

本程序只读取键盘鼠标按键，只在屏幕上画一个透明窗口。不读取、不修改游戏文件和内存，不注入游戏，不模拟按键。

系统要求：Windows 10/11（或 .NET Framework 4.7 以上）。不用另外安装任何东西。
程序启动时会请求以管理员身份运行（Windows 会弹窗确认，点「是」）：塔科夫是用管理员权限运行的，Windows 不允许普通程序读它的按键，不给这个权限，准星在游戏里就不会跟着动。

==================================================
【每把枪要不要单独调？】
==================================================
不需要。
- 偏移量是固定值，换枪不用改。
- 每把枪只有后坐力不同。后坐力可以单独改，但不推荐。
- 开发者实测：后坐力 50 到 100 的枪，用同一套设置就够了，近距离差别不大。
- 真想每把枪一套也可以：顶部「管理 ▾」→「新建…」或「复制…」，每把枪存一套配置，用顶部「配置」下拉框切换。

【安装 / 运行】
==================================================
1. 把压缩包整个解压到一个固定文件夹，比如 D:\TarkovHipAimer。
   不要在压缩包里直接双击运行。
2. 双击「准星 TarkovHipAimer.exe」。不用安装，双击就能用。
3. 程序常驻在右下角托盘。双击托盘图标打开设置；右键托盘图标有「打开设置」「启用准星」「启用滤镜」「退出」。
4. 程序已经在运行时再双击「准星 TarkovHipAimer.exe」，会直接打开设置窗口。

==================================================
【升级（从旧版本换到 v5.1）】
==================================================
1. 旧版本开了「开机自动启动」的：先在旧版本里取消「开机自动启动」（v4.0 在「分辨率 · 常规」页，v3.x 在「其他」页）。
2. 右键托盘图标 →「退出」，关掉旧版本。
3. 把 v5.1 解压到一个新文件夹，双击里面的「准星 TarkovHipAimer.exe」。
4. 第一次打开会问「用过旧版吗？」：点「选择旧的 settings.json」，选旧文件夹或里面的 settings.json，
   你以前调好的所有配置和按键都会导进来。以后也可以在「管理 ▾」→「导入旧版设置…」里导入。
   导入时，这台电脑现在的这些设置保持不变，不会被旧文件覆盖：游戏分辨率、画面比例、FOV、调参基准。
   （也可以手动：把旧的 settings.json 复制到新文件夹，和「准星 TarkovHipAimer.exe」放在同一层；第一次启动时会自动移进「数据 Data」。）
   从 v5.0.2 或更早版本升级：你的配置和按键都会保留。新功能（弹药提示、丢雷隐藏、站立静止偏移等）用默认值；
   强化键以前是鼠标上侧键的，会保留原来的键；想改成和战术装置模式键一样，到「按键」页改成 Ctrl+T。
   第一次打开 v5.1 时会出现一次「首次设置向导」，里面已经填好你原来的分辨率、画面比例和 FOV，看一遍点「下一步」就行。
5. 需要开机自动启动的，在新版本「分辨率 · 常规」页重新勾上「开机自动启动」。
6. 确认没问题后，再删掉旧文件夹。

读旧设置时会自动处理：
- 前后左右固定为 W / S / A / D。旧设置里改过的，会自动换回 W / S / A / D。
- 其他按键原样保留，现在还可以设组合键（比如 Ctrl+D）。
- 旧版设置文件打开后数值完全不变（按 2160×1440、FOV 75、跟随分辨率换算，和以前一样）。

【卸载】
==================================================
1. 打开设置 →「分辨率 · 常规」页，取消「开机自动启动」。
2. 右键托盘图标 →「退出」。
3. 删除整个文件夹。设置都在文件夹里的「数据 Data」，电脑别处不留东西。

  「恢复 ▾」 ……… 恢复到你存的默认，或「恢复到 Leo 推荐」（名字、按键和全局设置不变；恢复到 Leo 推荐时外观也不变）
  「高级设置」 …… 见下面【高级设置】

每一页都可以点「上一步」回去改。向导里填的都能以后在设置页改；首页的「设置向导」按钮可以再做一遍。

向导做完会问要不要看教程。教程用动画讲每个功能怎么调，可以跳过；以后点菜单最下面的「设置教程」再看：
   为什么做这个 · 落点在右下 · 后坐力上抬 · 移动的惯性 · 去靶场 · 左右 A / D · 前后 W / S ·
   站立静止偏移（可选） · 短按与反向 · 侧身 Q / E · 换手 · 跳跃与拉枪 · 开镜时完全隐藏 · 丢雷时隐藏 ·
   强化准星 · 弹药提示（主武器）
   开发者的话：站着不动时，准星默认在屏幕正中间；如果站着开枪弹孔也偏，可以填「站立静止偏移」。近距离对枪基本都在移动中，这个工具最重要的是让移动扫射时准星对准弹孔。
- 每一页都有「跳过本步」「退出教程」；要填的数可以先跳过，用默认值；填的数直接存进当前配置。
- 教程没看完就关掉，下次打开会接着上次的位置。
- 最后一页点「完成，去精调」，再按下面的方法一页一页精调。

==================================================
【调试方法（按设置页顺序）】
==================================================
开始前：
- 进藏身处靶场或练习模式，穿上你常穿的装备，拿最常用的枪。
- 找一面干净的墙，站在大约 10 米远。以后每次调都用同一个距离。
- 每次只改一个数，改完打几发再看。
- 调之前可以先点顶部「存为我的默认」；调乱了点「恢复 ▾」回来。
- 站着不动时，准星默认在屏幕正中间。想让站着时也偏一点，用「移动」页的「站立静止偏移」（见下面）。

偏移量的单位：百分比偏移
- 屏幕中心到屏幕上边缘算 100%。例：「← 4.17%」= 往左偏，距离是中心到上边缘的 4.17%。
  左右（X）和上下（Y）都按这个算。
- 箭头是方向（← → ↑ ↓），数字是大小，保留两位小数。
  点数字左边的箭头换方向；输入框的上下箭头每次改 0.10%，直接输入可以精确到 0.01%。
- 用百分比，换分辨率不用重调：1080p、1440p、4K、带鱼屏都是同一个数。
- FOV 也自动换算：内置数值是在 FOV 75 下调的。你的游戏 FOV 不是 75 时，在「分辨率 · 常规」页填对 FOV，
  程序会自动换算，不用自己改数。
- 设置文件里照样按像素保存，旧版本的设置不受影响。

01 首页
------------------------------
只看不改。
- 顶部「状态栏」：用文字显示准星现在的状态，例如「已隐藏：开镜」「已隐藏：丢雷」「强化：开」「黄色 = 换手中」。
  旁边有「必读」「常见问题」「设置向导」按钮。
- 「准星实时轨迹 · 象限图」：准星在中间，按键时准星移动并画出轨迹线。
- 「实时数据」：X 偏移、Y 偏移、上抬偏移量、侧身、持枪手、方向、状态。
- 「按键」：你现在按着哪些键。
- 下面的小终端：实时计算记录。
- 顶部右边「内存」：程序现在占用的内存。
- 设置窗口不在前台时，首页暂停读取按键，回到窗口就继续。

------------------------------
02 按键
------------------------------
- 点按键旁边的按钮，出现「请按键…（Esc 取消）」时按下新按键或鼠标键。
- 「开镜方式」「侧身方式」「换手方式」（按住 / 点一下切换）要和游戏里的设置一样。
- W A S D 固定为前后左右，不用改，也改不了。
- 可以改的键：开关准星、开火、开镜、左侧身、右侧身、换手、跳跃
  （打开「高级设置」后还有：自由视角（转头））。
- 某个键已经被别的功能用了，会问你「换过来吗？」：点「是」两个功能互换按键（W A S D 不能换，按它会同时移动）。
- 「按键恢复初始」：这一页的按键和方式全部回到第一次安装时的样子。

组合键：
- 先按住 Ctrl / Shift / Alt，再按另一个键，就会显示成组合键，比如「Ctrl+D」。
- 按组合键时只算组合键。例：右侧身设成 Ctrl+D，按 Ctrl+D 只算右侧身，
  准星不会往右移；单独按 D 还是往右走。

游戏按键（要和游戏里一样）：
- 「强化准星」= 游戏里「切换战术装置模式」的键，默认 Ctrl+T。「强化方式」：切换（默认）或按住。见下面【强化准星】。
- 「丢雷隐藏」：默认 G。见下面【丢雷隐藏】。
- 「弹药提示」：弹匣容量、射速、换弹键（默认 R）、换弹时间、快速换弹时间。见下面【弹药提示】。
这些键程序不会去游戏文件里读，要你自己照游戏设置填。

冲刺取消开镜 / 侧身（只在「点一下切换」时出现）：
- 「冲刺（Shift+W）取消开镜」：开镜方式是「点一下切换」时才显示，默认开。
  按住 W 再按 Shift 冲刺，退出开镜，准星自动回来。
- 「冲刺（Shift+W）取消侧身」：侧身方式是「点一下切换」时才显示，默认开。
  按住 W 再按 Shift 冲刺，侧身自动回正。
  这个勾在「按键」页改；「侧身」页只显示开 / 关。
- 只按 Shift（屏息）不算冲刺。
- 方式是「按住」时，冲刺不影响开镜和侧身（松开按键就结束）。

------------------------------
03 分辨率 · 常规
------------------------------
（菜单里叫「常规」。）
- 「游戏分辨率」：第一次启动时已经自动填成你主显示器的真实分辨率。
  和游戏里不一样就改成游戏里的；点「自动检测」可以重新自动填。
- 这页只有游戏里也有的 3 项：「游戏分辨率」「画面比例」「FOV」（视野，50–75），照游戏设置里填。
  偏移量会按视角自动换算到你的画面，不用自己重新调。
- 「画面比例」：照游戏设置选，常用的有 16:9、16:10、21:9、32:9、4:3、5:4、3:2、1:1；也可以自定义 宽:高，例如 123:111。
  选的比例和屏幕本身的比例不一样时，会问「画面有没有被拉宽」，页面上显示左右偏移怎么换算，例如「横向 ×1.20（拉伸）」。
  怎么判断见下面【画面比例和拉伸】。
- 页面上会实时显示「换算系数」和 1% 等于多少像素。1% 只看分辨率和画面比例（画面中心到上边缘的百分之一），和 FOV 无关。
  FOV 调小，换算系数变大：同一套设置在屏幕上离中心更远，各页显示的百分比也跟着变大
  （例：FOV 75 时的「← 4.17%」，FOV 50 时显示「← 6.86%」）。程序自动换算，不用自己改数。
- 内置偏移是在 2160×1440、FOV 75 上调的。「调参基准」不是游戏设置，只在「高级设置」里，一般不用动。
- 「只在塔科夫前台时显示」（默认开）：切出游戏时准星自动隐藏，也不读按键。
  这个设置窗口在前台时准星照常显示。
- 「开机自动启动」（默认关）：登录 Windows 后自动在托盘里启动。用的是 Windows 计划任务（登录时不再弹确认），只对你这个账户生效。
- 「性能模式」（默认关）：关掉设置窗口里的动画和发光，界面每秒最多 30 帧；游戏里的准星完全不受影响。
- 「自动检查更新」（默认开）：见上面【联网和隐私】。

------------------------------
04 后坐力
------------------------------
- 只需要填「上抬偏移量」：站着不动，对墙按住开火连续开枪，
  看弹孔往上跳了多少，准星就抬多少。
- 只管上下（Y），左右（X）先不管，后面在移动里调。
- 后坐力 50–100 的枪用同一套数值就够，近距离差别不大。
- 开镜时不算后坐力。

------------------------------
05 移动（W 前 / S 后 / A 左 / D 右）
------------------------------
1. 后坐力调好后，单独按住 D 往右走，同时开枪，改「D 右」的左右（X），让准星套住弹孔。
2. 单独按住 A，同样改「A 左」的左右（X）。
3. 单独按住 W、S，改「W 前」「S 后」的上下（Y）。
- A / D 的上下一般不改；W / S 的左右一般不改。上下的偏差最好交给后坐力。
- 斜着走（WA / WD / SA / SD）自动计算，不用调。
- 侧身 + 移动 = 两个偏移直接相加。

站立静止偏移（可选，默认 0）：
- 站着不动开枪，弹孔不在屏幕中心时才用。默认 0 = 站着时准星在屏幕正中间。
- 填了以后，站立点就是新的零点。其他方向的偏移会自动换算，准星在屏幕上的位置保持不变，不用重调。
  例：站立设成「→ 1.00%」，原来「D 右」是「← 4.17%」（离屏幕中心），换算后显示「← 5.17%」（离站立点）。
- 改之前会弹窗确认，点「确定」才改。
- 快速按两下 F12（关再开）复位时，准星回到站立点。

短按和反向：
- 轻点一下 A 或 D（很短的按键），准星只动一点点，并按按下的时间原路回来，和游戏里一样。
- 按着 A 直接换成 D 时，准星从现在的位置先减速、再往另一边加速，不会一下子跳到右边。
- 打开「高级设置」后，「短按和换向」里可以改：「短按阈值」（默认 120 ms，短于它算轻点）、「换向最短时间」（默认 150 ms）、「换向停顿」。
  改完马上生效，可以直接试：开着首页的面板（或进游戏），轻点一下 A，准星只动一点就回来；按住 A 再换 D，看换向快不快。

------------------------------
06 侧身
------------------------------
- 站着不动，按左侧身开枪，改「左侧身」的左右 / 上下，让准星大概套住弹孔。右侧身同样。
- 侧身 + 移动 = 两个偏移直接相加。按住 Q+A、E+D 开枪检查；
  不准就微调侧身，不要再动 A、D。
- 「侧身方式」和「按键」页是同一个设置，要和游戏里一样。

------------------------------
07 换手
------------------------------
- 按换手键（默认鼠标下侧键，侧键1）换手，准星会变成换手颜色（默认橙色），状态栏显示「黄色 = 换手中」。
- 换手后的偏移默认是正常手左右镜像，格子显示灰色「自动」。
  但游戏里换手不是绝对镜像，换手后要把上面的测试全部再做一遍。
- 哪一格不准就直接改，改过的格子用你自己的数；
  点那一行的「恢复自动」回到镜像，「全部恢复自动」一次恢复全部。
- 程序只能靠按键判断你用哪只手。对不上时按两下开关准星键（默认 F12，关再开），回到正常手。

------------------------------
08 跳跃
------------------------------
- 「跳跃时准星跟着动」（默认开）：按一下跳跃键跳一次，准星按预设路线动
  （先往下 → 再往上 → 回到起点），页面下方画出路线。
- 默认就是开发者调好的路线。一般只改「总时长」。
- 打开「高级设置」后可以改每一段的时长、结束位置和曲线；「自动分配」把三段按 30% / 40% / 30% 分好。

09 外观
------------------------------
- 「准星样式」：点一下就换上，右边实时预览。分三组：
  推荐 · 中心留空：宽距三角、双层箭头、中空十字（默认）、T 形（无上）、斜十字、左右横线、四角框、
                  括号 [ ]、点阵圆环、分段圆弧、下半弧、四点、圆环 + 刻度、竞速（斜切短格子）、空心菱形、空心三角
  经典：经典圆环、虚线圆环、方框、圆环 + 十字
  自定义：自定义图片（上传自己的 PNG）
- 选中样式后可以改大小、线宽等参数，以及「颜色 · 描边 · 透明度」。
- 「外观」页顶部有三个小页：准星样式、准星动态、弹药提示。
- 「准星动态」：预设 静态（默认，准星永远不动）／跟随动作（移动时张开，开火时每一发张开一下）／开火跳动（只在开火时张开）／
  开火特效（开火张开 + 波纹 + 渐变色）／竞速（干脆的张开 + 快速的红色波纹）。每个效果都能单独开关和调数值：张开幅度、张开速度、
  恢复时间；开火波纹的颜色、速度、宽度、距离、褪色时间；开火渐变色的中心颜色、外圈颜色、扩散时间、褪色时间；开火效果强度。
  页面上有实时预览。这些效果都不增加延迟，中心始终空着，开镜、丢雷时完全看不到。
- 「弹药提示样式」：见下面【弹药提示】。
- 换手颜色、发光 / 羽化 / 旋转，在「高级设置」里。强化准星（按强化键后）可以单独设一整套外观：在「高级设置」里
  「强化准星」点「改强化准星的样子」，整页的样式、大小、颜色、描边、发光、中心留空、自定义图片就都改强化准星；改完点「改回正常准星」。
  「和正常准星一样」把强化准星改成和正常准星一模一样。

------------------------------
10 滤镜
------------------------------
滤镜调整显示器的颜色曲线：暗处更亮、太亮的地方不刺眼、颜色更清楚。
它只改显示器的颜色曲线，不截图、不读游戏；退出程序时自动恢复原画面。
如果程序意外关掉、画面没恢复：重新打开程序，它启动时会先把画面恢复。
第一次运行时滤镜是关的：勾上「开启滤镜」或按 F8 打开。
滤镜开着也不占 CPU：只有你按快捷键或改设置时才工作。
- 「预设」：自带两个：「通用」（开发者自己用的设置，含显卡数字振动 +5，即饱和度 55）和「黑夜模式」（暗部提得更多，适合夜图）。
  其他是你自己存的预设。选好再用「调试滤镜」调亮或调暗。
- 「另存为…」把现在的数值存成新预设；「保存」存进当前预设；自己的预设可以「重命名…」「删除」；自带预设可以「恢复出厂」。
- 「调试滤镜」：11 格，从 -5 到 +5。往右更亮（暗部提得更多），往左更暗，0 就是当前预设；
  下面的滑块会跟着一起变，饱和度不变。满意了点「另存为…」或「保存」。
- 「色调曲线」：横着看是原来的亮度，竖着看是滤镜后的亮度，虚线＝不改。曲线上有 5 个点（黑位、暗部、中间调、高光、白位），
  可以直接上下拖（点一下曲线后也能用方向键），下面的滑块会跟着变；曲线下面实时显示每个点「原来 → 现在」的亮度。
  拖到某个位置拖不动了：已到 Windows 允许的最大值。Windows 不接受离原来太远的颜色曲线，再拉会被拒绝，所以程序在这里停住。
  滤镜不截图、不读游戏画面，所以没有直方图。
- 「存为 A」「存为 B」「A / B 切换」：存两套设置来回切，对比哪个更清楚。
- 「按住看原画面」（或按住 F7）：按住时看没加滤镜的画面，松开恢复。
- 「全部恢复原样」：滤镜关掉，颜色曲线、饱和度和显示器亮度 / 对比度 / 锐度都恢复到打开程序前的样子。
- 「滤镜教程」：一步一步看每个设置的作用，不会改你的屏幕。
基础设置（鼠标停在设置上会显示详细说明）：
- 提亮暗部：把暗处调亮，看清阴影里的人和东西。
- 暗部范围：决定「提亮暗部」管多大范围：负值只管最黑处，正值管得更宽。
- 压低高光：把太亮的地方压暗，天空和灯光不再刺眼。
- 黑位：正值让最黑的地方变灰一点、能看出细节；负值让黑色更黑。
- 中间调：调整画面大部分区域的明暗，正值更亮，负值更暗。
- 饱和度：先勾「改饱和度」；50 不变，往上更浓，往下更淡。
- 饱和度方式：显卡驱动（推荐，默认）或 Windows 放大镜。
「显示器硬件」（默认收起，点开后才检测显示器）：直接改显示器本身的亮度、对比度、锐度（显示器要支持 DDC/CI）。勾上「改」才会改；
  显示器不支持的项显示「不支持」，锐度不支持时不显示。只在滤镜开着时生效，关掉滤镜或退出时改回原来的值。
「分享码」：点「复制分享码」把现在的设置发给朋友；把别人的分享码粘贴进去点「导入」，会存成一个新预设，不会覆盖已有的。
  只能导入本程序导出的分享码（TSHADE2 开头）。
滤镜快捷键（默认，在这一页的「快捷键」里改）：
  F8 开关滤镜，F9 下一个预设，F7 按住看原画面。
  只能用 F1–F24 或带 Ctrl / Shift / Alt 的组合键，不能重复，也不能和准星的按键用同一个键。

------------------------------
开发者的话
------------------------------
最好的拉枪方式有两种：右手持枪按 D+E，相对速度最快；或者换手后按 Q+A，同样好用。

战术手电推荐 WMX200，PVP 最优选：平时开红外（IR），接敌时按 Ctrl+T 切到手电。
WMX200 是我实测光遮蔽效果最大的手电。切到手电时强化准星会一起打开，近距离更好看清。

==================================================
【弹药提示（默认关）】
==================================================
在准星旁边提示主武器弹匣里大概还剩多少子弹。只显示范围，不显示数字：
  满 → 大半 → 一半 → 少 → 快空
- 在「按键」页勾上「显示弹药提示（只算主武器）」，填「弹匣容量」（例如 30）和「射速」（每分钟发数，RPM），选全自动或半自动。
- 全自动：按住开火的时间 × 射速 = 打出去的子弹数。半自动：点一下算一发。
- 换弹：按 R = 普通换弹，快速按两下 R = 快速换弹。两种都是换上一个新的满弹匣：换弹时间到了，提示变成满。
  动画里旧弹匣滑出去、新的满弹匣滑进来；快速换弹更快，旧弹匣是丢掉的。双击判定时间默认 300 毫秒。
- 「换弹时间」（默认 2400 毫秒）和「快速换弹时间」（默认 900 毫秒）在「按键」页改，首页「常调」里也能改（局内可调）。
- 开镜和丢雷时，弹药提示和准星一起隐藏。
- 样式在「外观」→「弹药提示」：一根小条，默认在准星下方。预设 简洁／CF 风格／科幻／点阵／粗条／胶囊／竞速（斜切的换挡灯格子，
  绿 → 黄 → 红，黑色底板），选完还能改位置、长度、粗细、离准星距离、分段、圆角、发光、背景槽、外框、每一档的颜色、淡入。
- 「只在剩余少于 X% 时显示」（默认关，X 默认 35%）。
- 低弹警告（默认开，少于 15%）和紧急警告（默认关）：各自的比例、方式（闪烁／呼吸／变色／发光／闪几下后常亮／常亮）、速度、颜色、强度。
- 换弹动画：普通换弹和快速换弹各自设置动画、方向、用时比例、快慢曲线、换弹标记、旧弹匣掉落、换弹时的颜色；有「预览普通换弹」「预览快速换弹」按钮。
  弹药提示只改提示自己的颜色，不改准星的颜色；准星中心始终空着。
- 提示和弹匣对不上时：按一次换弹键，提示回到满。

==================================================
【丢雷隐藏（默认开）】
==================================================
- 按 G（游戏默认的丢雷键）准星隐藏，和开镜时一样完全看不到。
- 再按一次 G，准星才重新出来。它不会自己回来。
- 忘了按回来：快速按两下 F12（关再开）也会让准星出来。
- 丢雷键可以在「按键」页改；不需要这个功能可以关掉。
- 状态栏会显示「已隐藏：丢雷」。

==================================================
【强化准星】
==================================================
用法（推荐）：
1. 战术装置（推荐 WMX200）用 T 打开，切到红外（IR）模式，一直开着。
2. 接敌时按 Ctrl+T（游戏里「切换战术装置模式」）切到手电 → 强化准星打开，准星更显眼。
3. 再按 Ctrl+T 切回红外 → 强化准星关闭。
- 每按一次强化键，强化就开 / 关一次。单独按 T 不影响强化。
- 「强化方式」：切换（默认，按一下开、再按一下关）或按住（按住时显示）。
- 强化和手电对不上时：先把装置切回红外，再快速按两下 F12，强化回到关闭。
- 强化准星的样子在「外观」→「高级设置」里单独设。

【高级设置】
==================================================
顶部的「高级设置」开关，默认关。
- 关着时，每一页只显示一般玩家需要的选项。
- 打开后，每一页多出更细的选项；关掉只是隐藏，数值不变。
- 打开后多出来的：
  按键 ……………… 自由视角（转头）+「按住时隐藏准星」、
                    「换手检测」、「Alt / Ctrl + 右键不算开镜」、「Tab / Esc 取消开镜」（点一下切换时）
  分辨率 · 常规 … 显示器、出现渐变、消失渐变、窗口标题 +「从打开的窗口里选 ▾」、
                    设置窗口置顶、启动时打开设置、启动动画、打开设置文件夹、调参基准、贴图变糊排查（见下面）
  后坐力 ………… 「可选：更多后坐力参数」：到顶时间、每次按下额外上跳、松开回落时间、
                    开枪后多久开始上跳、到顶时水平偏移
  移动 …………… 「可选：移动快慢（推荐＝Leo 的方案）」：
                    推荐是左右、前后都用 430 ms（和内置「Leo默认」一样）；点「恢复推荐」回到推荐
  侧身 …………… 过渡时间
  换手 …………… 换手过渡时间
  跳跃 …………… 每一段（先往下 / 再往上 / 回到起点）的时长、结束位置、曲线，和「自动分配」
  外观 …………… 发光 · 羽化 · 旋转、换手颜色、强化准星（按强化键后，可单独设整套外观）
  滤镜 …………… 白位、中间对比、色温、自然色彩、高光范围、过渡柔和、「只在游戏窗口在前面时响应快捷键」
一般不用开。默认值就是推荐方案。

贴图变糊排查（「分辨率 · 常规」页，高级设置，三个选项默认都关）：
- 有些电脑开着准星（或者 KOOK 说话浮窗、任务管理器盖在游戏上）时，塔科夫的贴图会变糊，关掉准星马上变清楚。下面三个选项用来排查和缓解。
- 开镜/丢雷时真正隐藏准星窗口：开镜或丢雷时把准星窗口整个关掉，而不是只变透明。
- 新的显示方式（DirectComposition）：用另一种方式把准星交给 Windows 显示。电脑不支持时会自动换回原来的方式。
- 显存诊断日志：每秒把游戏用的显存写进「数据 Data」里的 crash.log，方便对比开 / 关准星时的区别。用完请关掉。

【自己上传准星图片（PNG）】
==================================================
1. 「外观」页选「自定义图片」，点「上传 PNG…」，选一张图片。
2. 图片会复制到「准星样式 Crosshairs」文件夹，较长的一边缩放到你设的大小。
3. 透明背景的 PNG 效果最好。可以勾「用准星颜色给图片上色」，换手颜色也会生效。

所有准星中间都是空的，包括你上传的图片（中间会自动挖空，至少 3 个像素）。
因为塔科夫要看屏幕中间的小点来找物资，这个点永远不会被挡住。

【分辨率和窗口自动适配】
==================================================
- 第一次启动自动读取主显示器的真实分辨率（不受 Windows 缩放影响），填进「游戏分辨率」。
  已有的 settings.json 不会被改。
- 准星覆盖整个主显示器，什么分辨率都可以。
- 准星自动跟显示器的刷新率同步，不需要设置。
- 设置窗口会跟着屏幕分辨率、Windows 缩放（100%–200%）和窗口大小自动调整，文字总是完整显示。

==================================================
【画面比例和拉伸】
==================================================
只有「画面比例」和屏幕本身的比例不一样时才需要看这一节（例如 16:10 的屏幕，游戏里选 4:3）。
这时游戏画面有两种样子：
- 拉宽了：画面铺满整个屏幕，东西看起来变胖（圆的东西变成横着的椭圆）。
- 有黑边：画面两边是黑的，中间的画面比例正常。
在「常规」页（或向导里）选你看到的那种：
- 拉宽了 → 左右偏移按拉伸倍数换算。例：16:10 屏幕选 4:3，横向 ×1.20，「← 5.00%」在屏幕上变成「← 6.00%」。
- 有黑边 → 左右偏移不乘这个倍数。
选错的表现：准星一边准、另一边偏得很多（偏移越大的方向偏得越明显）。这时换一个选项试试。

【常见问题】
==================================================
问：为什么开镜还有准星？
答：「开镜方式」和游戏里不一样。游戏里是按住开镜，这里也要选「按住」；游戏里是点一下开镜，这里选「点一下切换」。
    在「按键」页改。改对以后，开镜时准星会完全消失。

问：为什么准星变黄了？
答：程序以为你换手了（状态栏显示「黄色 = 换手中」）。没换手却变色：快速按两下 F12（关再开）回到正常手。

问：准星不显示？
答：1. 按一下 F12，可能被关了；或看顶部「启用准星」有没有勾上。
    2. 开镜（右键）、自由视角（中键）和丢雷（G）时准星本来就会隐藏；丢雷后要再按一次 G。看首页状态栏写的原因。
    3. 「只在塔科夫前台时显示」开着时，要先点进游戏窗口。
    4. 游戏显示模式请用「无边框窗口」。
       还是不出来：打开「高级设置」，在「分辨率 · 常规」页点「从打开的窗口里选 ▾」，选塔科夫的游戏窗口。

问：为什么准星不动（游戏里按键没反应）？
答：1. 启动时 Windows 问「是否允许」要点「是」（见上面【这是什么】），点「否」时程序不会启动。
    2. 「只在塔科夫前台时显示」开着时，要先点进游戏窗口。

问：准星一边准、另一边偏得很多？
答：多半是画面比例和拉伸选错了，见上面【画面比例和拉伸】。

问：双击「准星 TarkovHipAimer.exe」没反应？
答：先确认整个压缩包都解压了，不要在压缩包里直接运行。看一下右下角托盘，程序可能已经在运行了。
    还不行就把「数据 Data」文件夹里的 crash.log（如果有）发到上面的反馈渠道。

问：提示 .NET Framework 太旧？
答：更新 Windows，或从微软官网安装 .NET Framework 4.8，再双击「准星 TarkovHipAimer.exe」。

问：设置丢了？
答：设置存在「数据 Data」文件夹里的 settings.json（「数据 Data」就在「准星 TarkovHipAimer.exe」旁边）。
    换文件夹或升级时，把旧的 settings.json 复制到新文件夹，放在 exe 旁边就行：第一次启动会自动移进「数据 Data」，旧文件改名为 .old。
    文件损坏时程序会用默认设置启动，并把原文件另存为 settings.bad-日期.json。

问：每把枪都要调吗？
答：不用。见上面【每把枪要不要单独调？】。

问：换手后准星位置不对？
答：按两下 F12（关再开）回到正常手，再按换手键。

问：右侧身是 Ctrl+D，按了准星却往右走？
答：在「按键」页把右侧身重新设成组合键：先按住 Ctrl 再按 D，显示「Ctrl+D」就对了。

问：调乱了怎么办？
答：顶部「恢复 ▾」→ 恢复到你存的默认，或「恢复到 Leo 推荐」。按键用「按键」页的「按键恢复初始」。
