Tarkov Hip Aimer — by Leo   v3.6

【这是什么】
塔科夫腰射用的屏幕准星：在屏幕上画一个圆圈，跟着你的走路、侧身、开枪、跳跃、换手移动，
帮你估计不开镜时子弹大概落在哪里。每把枪可以存一套自己的配置。

【安装 / 运行】
1. 把压缩包解压到一个固定的文件夹（比如 D:\TarkovHipAimer）。
2. 双击 Start-HipAimer.bat。第一次会自动编译出 TarkovHipAimer.exe（用 Windows 自带的 .NET 4），
   然后弹出管理员确认，点“是”。以后再双击也一样，已经在运行时会直接打开设置窗口。
3. 程序在右下角托盘里，双击托盘图标打开设置。

文件夹里：
- Start-HipAimer.bat：启动器，双击它。
- README.txt：本说明和调试教程。
- settings.json：你的设置，第一次保存后出现。升级时把它复制到新文件夹的这一层。
- app 文件夹：程序本体，不用动。

【常用按键】（都可以在“按键”页改）
- F12：开 / 关准星。关了再开会回到正常手、取消强化准星。
- 鼠标侧键1（下侧键）：换手。换手后准星默认左右镜像（“换手”页可以逐项改），并换成“换手颜色”（默认橙色），可以在“外观”页改。
- 鼠标侧键2（上侧键）：强化准星，按一下变成更大更亮的准星，再按一下恢复（外观可以在“外观”页改）。
- 开镜（右键按住）和自由视角（中键按住）时准星自动隐藏。
- 开镜用「点一下切换」时：按 Tab/Esc 会当作取消开镜；Shift+W（冲刺）也当作取消开镜，只按 Shift（屏息）不算；Alt/Ctrl+右键（切倍率/切瞄具）不算开镜。这几项都在「按键」页，可以关掉。
- 空格：跳跃时准星跟着上下动（“跳跃”页）。

【调试教程（第一次用一定要看）】
内置的「Leo默认」是 Leo 的 M4 和装备调出来的。换枪、换装备、换配件后，按下面一步一步调。
设置窗口开着时准星照样显示，可以边打边调。改完的数会自动保存。
开始前先点顶部「保存为默认」，调乱了可以用「恢复默认」回来。

第 0 步：准备
1. 「按键」页：所有按键改成和游戏里一样。开镜方式、侧身方式（按住 / 点一下切换）也要和游戏一样。
2. 「其他」页：「游戏分辨率」填你游戏里的分辨率，或者点「用当前显示器」。
3. 设置窗口底部的「预览」选「实时（按键控制）」，不然游戏里按键不算。
4. 进藏身处靶场或离线模式，站在一面平的墙前面，离墙大约 10 米。
   距离很重要：近了远了落点都会变，以后调都用同一个距离。
5. 每次只改一个数，改完再打几发看看。

第 1 步：「移动」页 —— W / S / A / D 偏移
1. 按住 A 往左走，同时腰射扫射（按住左键），看弹孔落在哪里。
2. 改「A 左」的 X、Y，让圈套住弹孔。X 往右是正，Y 往上是正。
3. D、W、S 照样各调一遍。
4. 斜着走（WA、WD、SA、SD）不用调，程序自动算。可以按住 WA 扫射检查一下。
5. 下面的「移动速率曲线」管圈多快跟上：起步时圈总是慢半拍或者冲过头，就改总时长。
   左右 A/D、前后 W/S 各有一条。

第 2 步：「后坐力」页
1. 站着不动，对墙全自动扫射 2 秒。
2. 「最高上抬」：扫到后面弹孔最高到哪，圈就抬到哪。
3. 「到顶时间」：圈上去太快就调大，太慢就调小。
4. 「每次按下额外上跳」：单点几发，看每一发比圈高多少。
5. 「松开回落时间」：松开左键后，圈回到中间要多久。
6. 「到顶时水平偏移」：扫到顶时弹孔往左或往右偏多少。不需要改，只需要维持扫射移动精准即可，忽略这个设置。

第 3 步：「侧身」页 —— Q / E
1. 站着按住 Q，对墙扫射，改「Q 左侧身」的 X、Y，让圈套住弹孔。
2. E 照样调「E 右侧身」。
3. 再用侧身加移动细调：按住 Q+A 扫射，再按住 E+D 扫射。
   侧身加移动 = 两个偏移直接相加。这时不准，就微调 Q、E 的数，别再动 A、D。
4. 「过渡时间」：按下 Q / E 后圈多快移过去。

第 4 步：「换手」页
1. 按换手键（默认鼠标下侧键）换到另一只手，圈会变色。
2. 换手后的偏移默认是左右镜像（灰色「自动」）。但游戏里换手后不一定完全镜像，每一项都要再打一遍：
   A、D、W、S 扫射，站着扫射看「到顶时水平偏移」，Q、E 扫射。
3. 哪一格不准就直接改，改过的格子变白，用你自己的数。点「恢复自动」回到镜像。
4. 程序只能靠按键猜你是哪只手。对不上时按两下 F12（关再开），回到正常手。

第 5 步：「跳跃」页（可选）
勾上「跳跃时准星跟着动」，跳着扫射几次，按三段（先往下 / 再往上 / 回到起点）的时间和高度调。

第 6 步：收尾
1. 全部调好后，点顶部「保存为默认」。
2. 不同的枪可以复制一套配置分开存。
3. 游戏大更新后惯性可能会变，落点不准了就从第 1 步重新调。

【换手自定义】（“换手”页）
换手后的偏移默认是正常手的左右镜像（灰色“自动”，会跟着正常手一起变）。
哪一格不准就直接改，改过的格子用你自己的数；点“恢复自动”回到自动，“全部恢复自动”一次全恢复。

【只在塔科夫前台时显示】（“其他”页，默认开）
切到别的窗口时准星自动不显示，也不会读你的按键；切回游戏自动出现。
靠窗口标题判断，默认“EscapeFromTarkov”。如果没反应，点“从打开的窗口里选”选游戏窗口。
打开设置窗口时准星照样显示，方便调参。

【开机自动启动】（“其他”页，默认关）
勾上后登录 Windows 会自动在托盘里启动，不弹设置窗口。移动了文件夹也没关系，下次手动启动时会自动更新。

【卸载】
1. “其他”页取消“开机自动启动”。
2. 右键托盘图标 → 退出。
3. 删除整个文件夹（设置都存在里面的 settings.json）。

【风险】
BSG 禁止影响游戏客户端的软件。本程序只读取按键状态、在屏幕上画一个窗口，不碰游戏进程和内存。
