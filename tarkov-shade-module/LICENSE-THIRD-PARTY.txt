vibranceGUI (https://github.com/juv/vibranceGUI)

src/VibranceController.cs was written for this project; no vibranceGUI source
code was copied into it. The following interface facts were looked up in
vibranceGUI (commit 919a9f2) and are used in that file:
  - NVIDIA NvAPI function ID numbers (most were also confirmed in vibranceGUI's
    bundled vibranceDLL.dll binary; the comment in the file marks which);
  - the NV_DISPLAY_DVC_INFO struct layout and its version constant 0x00010010
    (from vibranceGUI NvidiaTypes.cs);
  - the AMD ADL constant ADL_DISPLAY_COLOR_SATURATION and the ADL struct layouts
    (from vibranceGUI AMD/vendor/adl64).
These are numbers and data layouts of the vendors' driver interfaces, not
program code. vibranceGUI shows no licence on GitHub (the GitHub API reported
"license": null on 2026-11-17), so it grants no rights to its code; do not
copy vibranceGUI code into this project.
